# AGENTS.md

Entry point for AI coding assistants working in this repository.

**[CLAUDE.md](./CLAUDE.md) is the canonical engineering handbook and the single
source of truth for this project.** It defines the architecture, coding
standards, security rules, and the RFC/ADR and documentation workflows.

Before making any change, read and follow **@CLAUDE.md**. If your platform does
not support file references, open and consult `CLAUDE.md` directly.

Key expectations (see CLAUDE.md for the full detail):

- Never document planned work as if it already exists.
- Create an RFC before architectural changes; record an ADR after they ship.
- Evaluate documentation impact for every task.
- Run the Validation Checklist and meet the Definition of Done before finishing.

This file intentionally stays short. It does not duplicate the handbook — it
points to it.
